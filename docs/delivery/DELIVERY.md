# Entregables y cadencia

## Paquete de cada hito

Cada hito entregará:

1. Código fuente versionado.
2. Recorrido demostrable.
3. Pruebas y resultado de ejecución.
4. Documentación funcional y técnica actualizada.
5. Registro de decisiones relevantes.
6. Limitaciones y riesgos abiertos.
7. Instrucciones exactas para reproducirlo.

## Ubicación

El proyecto vive en `C:\Users\georg\CODEX\supplier-hub`. Hasta H1 no se
publicará externamente. La publicación posterior se hará en un repositorio Git
público y mediante releases descargables; requerirá autorización antes de crear
o modificar recursos externos.

## Comunicación

Codex informará el resultado de cada hito, no cada detalle de implementación.
Solicitará decisión únicamente cuando falte autoridad o una elección cambie el
producto de forma material.

## Documentos reales

Las muestras reales se copiarán a un directorio local ignorado por Git, se
anonimizarán cuando sea razonable y nunca se incluirán en una publicación sin
autorización explícita.
