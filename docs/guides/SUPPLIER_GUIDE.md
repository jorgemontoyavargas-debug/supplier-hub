# Guía del proveedor

## Activar cuenta

1. Abre el enlace enviado por la empresa compradora.
2. Confirma tu nombre y crea una contraseña robusta.
3. El enlace queda invalidado después de utilizarlo.

## Enviar homologación

1. En el portal, selecciona **Iniciar homologación**.
2. Responde todos los campos obligatorios.
3. Adjunta documentos permitidos de máximo 10 MB.
4. Registra expedición y vencimiento cuando existan.
5. Guarda un borrador o envía para revisión.

Si el comprador solicita correcciones, el expediente vuelve a habilitarse. Las
versiones anteriores de los documentos se conservan para trazabilidad.

## Asistencia

La pantalla de asistencia muestra faltantes y puede analizar PDF localmente.
Toda extracción es una propuesta: verifica el texto y la página antes de
aceptarla. Supplier Hub no aprueba proveedores de forma automática.
