# Contribuir

Supplier Hub acepta mejoras que mantengan el núcleo gratuito, autoalojable y
exportable. Antes de enviar cambios:

1. Crea una rama pequeña y explica el problema de usuario.
2. Añade pruebas de éxito y autorización negativa cuando corresponda.
3. Ejecuta `scripts/verify.ps1`.
4. Actualiza documentación y ADR si cambia una frontera arquitectónica.
5. No incorpores SaaS obligatorio, telemetría externa ni activos de Fullstep.

Al contribuir aceptas que el cambio se distribuya bajo AGPL-3.0-only.
